ELDI EDU 33.0 — POSTAVLJANJE NA UPINITK

1. Otvorite cPanel / File Manager > public_html.
2. Postavite ELDI-EDU-33.0.0-UPINITK-public_html.zip i izaberite Extract.
3. Provjerite da postoji public_html/eldi-edu/index.html i public_html/eldi-edu/ucionica/index.html.
4. Otvorite https://upinitk.com/eldi-edu/ i kliknite Počni u pregledniku.
5. Pokrenite blokovski primjer i otvorite SQL bazu. Zatim preuzmite probni JSON rada.
6. Učenicima podijelite https://upinitk.com/eldi-edu/ucionica/.

ZIP sadrži samostalnu statičku web radionicu. PHP, MySQL, Node.js server i prijava nisu potrebni. Postojeću početnu stranicu UPINITK ne zamjenjuje: sadržaj je u novoj mapi eldi-edu/. Koristite HTTPS.

Sve biblioteke su uključene. Preglednik treba podržavati Web Workers, WebAssembly i IndexedDB. 3D ima jednostavniji prikaz za slabije računare. Hosting mora posluživati .js, .css i .wasm datoteke; ako SQL ne radi, provjerite da hosting nije zabranio .wasm (preporučeni tip application/wasm).

EXE i veliki kompletni ZIP preuzimaju se s GitHub izdanja v33.0.0. Ne morate ih smještati u public_html. Windows izdanje uključuje i stare zbirke, Scratch i Python/C/C++/Java.

Radovi se čuvaju lokalno u pregledniku učenika. Prenose se JSON datotekama; ovo nije zajednička serverska učionica. Za prvi čas pročitajte eldi-edu/PRVI-CAS-33.txt.
